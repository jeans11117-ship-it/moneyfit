# 머니핏 (MoneyFit)

한국 직장인을 위한 생활 금융 시뮬레이션 서비스입니다. 단순 계산값을 넘어 “내 월급과 자산으로 어디까지 가능할까?”를 직관적인 결과 카드와 해석으로 보여줍니다.

## 현재 구현된 기능

- 반응형 메인 페이지와 계산기 탐색 UI
- 내 연봉으로 살 수 있는 집 계산기
  - 보유 현금, 기존 대출, LTV, DSR 동시 반영
  - 예상 최대 주택가격, 주담대, 자기자본, 월 상환액 계산
- DSR 계산기
  - 주담대, 신용대출, 자동차 할부, 기타 대출 개별 입력
  - 안정·주의·위험 게이지와 추가 대출 여력 추정
- 로그인 없는 즐겨찾기와 최근 사용 계산기
- 결과 공유, SEO 메타데이터, 구조화 데이터, FAQ
- 재사용 가능한 광고 자리 컴포넌트

## 실행 방법

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 검증

```bash
npm run build
npm test
```

금융 규정과 기본값은 `config/financialRules.ts`, 계산 로직은 `lib/calculators`에서 관리합니다.

## 안내

이 서비스의 모든 계산 결과는 참고용이며 실제 금융기관, 세무기관, 정부기관의 산정 결과와 다를 수 있습니다. 투자 관련 계산 결과는 투자 권유가 아닙니다.
